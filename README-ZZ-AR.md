# ZZ Media — نسخة خاصة مبنية على YTDLnis

## ما يقدمه هذا التعديل

- يحتفظ بكامل مشروع YTDLnis المصدر المفتوح، ومحرك yt-dlp، وواجهة تحديد جودة الصوت والفيديو، والطوابير، والسجل، والإعدادات الموجودة في الأصل.
- يضيف متصفح WebView داخليًا بواجهة داكنة عربية واختصارات YouTube، TikTok، Instagram، Facebook، X، Threads، Reddit، SoundCloud، Vimeo، Dailymotion، Pinterest، Twitch.
- عند الضغط على **تنزيل** يرسل رابط الصفحة الحالية إلى واجهة تنزيل YTDLnis الأصلية (ShareActivity)، حيث تُفحص الجودات والصيغ الممكنة.
- زر **محرك التحميل** يفتح YTDLnis الأصلية، وزر **التنزيلات** يفتح سجلها.
- يسمح بفتح روابط HTTP(S) الأخرى من شريط العنوان، دون وعد بدعم استخراج الوسائط من جميعها.
- يبني ملف arm64 فقط باسم `zz-arm64-v8a-debug.apk` ضمن GitHub Actions > Artifacts.

## ملاحظات مهمة

- بعض مواقع التواصل تقيّد الوصول من WebView أو تشترط تسجيل دخول، ورابط المنشور لا يكفي دائمًا. ملفات تعريف الارتباط في متصفح WebView لا تُرسل تلقائيًا إلى yt-dlp؛ استخدم إعدادات ملفات تعريف الارتباط الخاصة بـYTDLnis عند الحاجة وبما يتفق مع شروط الموقع.
- المحتوى المحمي بـDRM أو الوسائط التي لا يدعمها yt-dlp لا يمكن ضمان تنزيلها، ولا يقدّم هذا التعديل تجاوزًا للحماية.
- قد تحتاج حزم YTDLnis المساعدة أو تحديث yt-dlp إلى التنزيل بعد التثبيت. تشغيل المحرك الأساسي لأول مرة والاطلاع على معالج الإعداد قد يكون ضروريًا.
- هذه حزمة **شيفرة مصدرية وأتمتة بناء**؛ ملف APK نفسه يُنتجه GitHub Actions بعد رفع المستودع. لا يوجد تأكيد لنجاح البناء حتى ينتهي التشغيل بنجاح.
- رمز التطبيق الأولي يستعمل أيقونات المشروع الأصلية، ويمكن تغيير العلامة والأيقونات لاحقًا.
- المصدر الأصلي © Denis Çerri ومساهمو YTDLnis، والرخصة GNU GPLv3 (تظل `LICENSE` وحقوق أصحابها الأصلية في نسخة المصدر). عند التوزيع يجب الالتزام بالرخصة وإتاحة شفرة التعديلات.

## خطوات Termux

1. نزّل ملف `ZZ-YTDLnis-Setup.zip` إلى مجلد `Download` في هاتفك.
2. افتح **Termux الأصلي** (وليس Ubuntu proot) ونفّذ:

```sh
termux-setup-storage
pkg install -y git curl unzip python tar
mkdir -p "$HOME/zz-installer"
unzip -o "$HOME/storage/downloads/ZZ-YTDLnis-Setup.zip" -d "$HOME/zz-installer"
bash "$HOME/zz-installer/ZZ-YTDLnis-Setup/setup-termux.sh"
```

3. سيرفع المشروع إلى `hald2020aa-hue/zz` بالحساب المسجّل في `git`/`gh`، وستبدأ GitHub Actions عند push.
4. افتح `https://github.com/hald2020aa-hue/zz/actions`، ثم عند اكتمال `ZZ Media - arm64 Debug APK` نزّل Artifact `ZZ-Media-arm64-v8a-debug`.

## التحقق

يوقف سير البناء عملية رفع الـAPK إن غاب الملف أو لم يتضمن `classes.dex` أو كان حجمه مريبًا (أقل من 15 ميجابايت). شرط الحجم فحص أولي فقط، وليس ضمان سلامة الوظائف. اختبر فتح الفيديو واختيار الجودة والتنزيل على جهازك فعليًا.
